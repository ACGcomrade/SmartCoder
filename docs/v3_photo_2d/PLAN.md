# 二维照片 demo：实现前冻结的实验计划

2026-09-06，v0.3。顺序：README 目标/硬规则 → RESEARCH_2D 调研与数学推导 → 本预注册 → 小算例 → 照片实现 → 结果。研究完成后确定本方案；若失败，保留失败记录，不回改下列阈值迁就数据。

输入固定为六张不同主体照片：Grace Hopper、猫 Chelsea、咖啡、火箭、Hubble 深空、硬币；分别使用原生尺寸，不人工裁切/降分辨率。6 张 / 3 个素域 / 每域 2 张已获用户确认。照片数量不通过复制或切块扩大。

## Hypotheses 与失败条件

| 编号 | 验收条件（不满足即失败） | 对照 |
|---|---|---|
| H1 恢复 | 同一个最终 base 恢复所有六张；尺寸全匹配，量化数字零误差；原始 RGB 每通道最大误差≤2、每图 PSNR≥42.1102 dB | 仅量化/反量化结果必须逐值一致，分离量化损失与存储损失 |
| H2 域计数 | 3 个固定素域、3 个 decoder，3≤6/2；每个返回两张；无专属权重、像素 metadata | 检查参数清单与 bundle 文件 |
| H3 局部写 | 每个槽各做一个 8×9 ROI 更新；每次只读写 216 个 base cell；其他照片及目标图 ROI 外逐值不变 | 更新前后完整解码（只用于验证，不算算法读取）；同域另一槽也需不变 |
| H4 整体写 | 批量 CRT、顺序写六张、逆序写六张得到同一个 base；六个槽整图替换与量化目标完全一致、不污染其他图 | 对比不同写入顺序，测量整图 cell 范围 |
| H5 独立恢复 | 新进程仅凭 base、无像素 manifest 和通用代码恢复六张；审计钩子禁止读取原图目录和网络 | 主动尝试原图访问必须被阻止；不声称审计钩子是安全沙箱 |
| H6 算术 | 64 状态/384 单槽变化通过；真实模数 M·max(p)<2^63；1000 个固定种子随机 CRT 对照 Python 整数，零差异 | 精确整数而非浮点近似 |
| H7 非空信息 | 零 base 对每张原图的 MSE>4，而真实 base MSE≤4 | 排除 decoder 单独生成输入；该门槛是明确的实验约定，不是普适图像定理 |

## 交付与接口

- `memory2d.py`：素数生成、CRT、二维状态、固定双输出 decoder、ROI/整图写、全局构造与本地 bundle 恢复。固定六槽；不做模型训练。
- `test_memory2d.py`：先运行小例与边界测试，再扩大到真实照片。
- `run_photo_demo.py`：核对照片来源与哈希、完成写入、独立恢复、测量上述 H、输出原图/恢复/放大误差对照图。
- `data/photos/` 与 `data/sources.json`：输入和溯源，仅编码/评估需要。
- `artifacts/photo_demo/bundle/`：最终 `base.npy`、`manifest.json`、解码代码；可独立复制恢复。
- `artifacts/photo_demo/recovered/`：从全部写入后的最终 base 恢复的 PNG。
- `artifacts/photo_demo/metrics.json`、`RESULTS.md`：真实结果、版本、存储开销与限制。

首次写入/整图替换使用整图矩形；已知局部变化用 ROI。未知 ROI 不提供自动定位承诺。全 base 构造只作初始化/一致性对照。暂不改变照片尺寸或动态增加域。

空间报告必须分别列出 uint64 base 负载、NPY 头、manifest、decoder 文件、原始 RGB 总字节、量化数组总字节、下载文件总字节与临时数组估计。访问计数是逻辑 cell，不是操作系统磁盘页。性能不是本阶段验收目标；不设置无依据速度指标。

完成后只能声称二维照片记忆、受限域数、近似恢复和局部更新得到支持；不能据此声称智能涌现、联想检索、压缩优于 JPEG/PNG 或强单 decoder 注入性。
