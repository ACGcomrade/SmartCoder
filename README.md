# SmartCoder

## 目标与课题主张

研究是否存在一种动态数学存储结构，在**部分激活、部分修改**的运行状态下形成 memory，并进一步研究 intelligence 能否由其动力学产生。

用户提出的结构直觉是：数学 list 承载共同底层状态 base，不同数学 field 支持不同 decoder，结果由 base 和 decoder 共同决定；不同结果可以部分重叠，但不要求它们相同，也不附加“同一对象的视图一致性”。

field 始终指抽象代数中的域。list 暂采用有限有序序列这一数学定义。one-to-one 保留严格单射的解释，并另列确定性较弱解释，避免把前者偷偷替换成后者。这个构想是待研究主张，不预先宣告成立。

## 2. 数学对象

**定义（项目选定）**：
\[
A=\{0,1,\ldots,M-1\},\qquad B=(b_1,\ldots,b_N)\in A^N.
\]

这是有限 list；\(B\) 表示完整 base，\(b_j\) 是一个局部状态。base 不等同于线性代数的 basis；也没有假定 list 自动具备域结构。

**定义（R1）**：域 \(F\) 配备加法和乘法；加法构成交换群，非零元素乘法构成交换群，并满足分配律。素数 \(p\) 对应 \(F_p=\mathbb Z/p\mathbb Z\)。

**定义（项目选定）**：decoder 是映射连同其域及参数：
\[
D=(F,\theta,d),\qquad d:\mathcal B\longrightarrow\mathcal Y_F.
\]
仅指定 field 还没指定 decoder。一个域上可以有许多函数；下面会写出实际运算。没有预设 decoder 一定是域同态；若要求保持加法、乘法、单位，须另加同态条件。

### one-to-one 的精确位置

\[
G:\mathcal B\times\mathcal D\longrightarrow\mathcal Y.
\]

“给定 \(B,D\) 有唯一结果”是函数性；严格 one-to-one 是：
\[
G(B,D)=G(B',D')\Longrightarrow B=B'\ \text{且}\ D=D'.
\]

本文先给一个满足带类型结果下严格单射的构造 A，再给一个只满足联合双射的 CRT 构造 B。两者作用不同。

跨域结果取不交并 \(\mathcal Y=\bigsqcup_D\mathcal Y_D\)，即结果有 decoder 的完整类型。这个类型包含域和算子参数，不包含 base。类型只区分 decoder；不能替有碰撞的 decoder 恢复 base。若要求无类型的纯数值结果本身区分所有 decoder，那是额外的像集不交要求；§3.4 单独给出满足它的构造。

## 3. 构造 A：严格单射的最小域解码器

### 3.1 推导

取素数 \(p\ge M\)，利用规范整数代表定义集合嵌入
\(\iota_p:A\hookrightarrow F_p\)。选择 \(\alpha_p\ne0,\ \beta_p\in F_p\)：
\[
d_p(b)=\alpha_p\iota_p(b)+\beta_p,\qquad
D_p(B)=(d_p(b_1),\ldots,d_p(b_N)).
\]

这是在域中的仿射运算；\(\iota_p\) 是集合嵌入，不将模 \(M\) 的加乘变成模 \(p\) 的加乘。特别是不能声称这里构造了不同特征域之间的保单位同态。（R1）

**P1：每个 \(D_p\) 在 \(A^N\) 上单射。**

若 \(d_p(b)=d_p(c)\)，则 \(\alpha_p(\iota_p(b)-\iota_p(c))=0\)。由于 \(\alpha_p\) 可逆，得到 \(\iota_p(b)=\iota_p(c)\)。二者均在 \([0,M)\subseteq[0,p)\)，因此 \(b=c\)。逐坐标即得结论。逆解：
\[
b=\operatorname{rep}_p\!\left(\alpha_p^{-1}(y-\beta_p)\right),
\]
并检查 \(b<M\)；不在像集内的输入应拒绝。

**P2：\(G(B,D)=(D,D(B))\) 对输入对严格单射。**

相同类型输出先给出同一个 D，再由 P1 给出同一个 B。这里输出的数值部分本身必须可逆；没有把 base 直接附在答案后面。但这也是明确的类型假设，不能将其叙述成“无类型数字天然区分所有解码器”。

### 3.2 可手算的 base case

取 \(M=6,N=2\)，\(B=(5,2)\)：

\[
d_7(b)=b+1\pmod7,\qquad d_{11}(b)=2b+1\pmod{11}.
\]

| 状态 | \(D_7(B)\in F_7^2\) | \(D_{11}(B)\in F_{11}^2\) |
|---|---|---|
| \(B=(5,2)\) | \((6,3)\) | \((0,5)\) |
| 只将 \(b_1\) 改成 3，\(B'=(3,2)\) | \((4,3)\) | \((7,5)\) |

读一个坐标，第一种 decoder 只需一次加法和一次模约简；第二种需一次乘法、一次加法和一次模约简。\(2^{-1}=6\pmod{11}\)，因此 \(D_{11}\) 的第一个结果 0 反解为：
\[
6(0-1)\equiv5\pmod{11}.
\]

只改动一个 list 元素，两个完整结果都发生改变，各自第二个分量保持不变。结果不同，允许部分结果重叠；全过程不需要“语义视图一致性”假设。

### 3.3 memory 如何成立

定义操作性记忆：先写入任意 \(v\)，输入撤去之后，只从持久 base 和固定 decoder 仍可恢复 \(v\)，且无关坐标的更新不破坏它。

对位置 j，目标域值 \(y\) 先按 P1 反解到合法 \(v\in A\)，然后令 \(b_j:=v\)，其余 \(b_k\) 不变。因此写后读满足 \(d_p(b_j)=y\)。任何仅作用于 \(k\ne j\) 的后续更新都不改变 \(b_j\)，所以回忆保持成立。decoder 无需保存 v。

这证明最弱的可写、可保留、可读取 memory；它是精确编码存储。没有学习到吸引子、联想补全或智能。A 中每个完整 decoder 都能反解全部 base，所以它们携带的可恢复 base 信息相同，数值结果和随后运算可以不同；独立记忆容量并未因此翻倍。

### 3.4 不附 decoder 标签也严格一一对应的补充构造

保留 \(A=\{0,\ldots,5\},N=2\)，改用：
\[
h_7(b)=b\pmod7,\qquad h_{13}(b)=b+6\pmod{13}.
\]
分别用规范整数表示结果。第一种的像为 \(\{0,\ldots,5\}\)，第二种为 \(\{6,\ldots,11\}\)，二者不交。因此对非空 list，纯数值结果的第一个分量已能确定用了哪一个 decoder；确定后逐项取原值或减 6，即唯一恢复 B。由此 \((B,H)\mapsto H(B)\) 在这个两-decoder 家族上严格单射，无需另附标签。

例如 \(B=(5,2)\) 得 \(H_7(B)=(5,2)\)、\(H_{13}(B)=(11,8)\)；只改第一个 cell 为 3 后得到 \((3,2)\) 和 \((9,8)\)。两个完整结果不同，各自未改位置的结果仍保留。这满足严格对应与局部更新，但一次局部回答仍不识别完整 list（见 P5）。

这里的 decoder 身份实际上由不交数值区间编码，消耗输出空间；不是免费区分。它只对固定的这两个 decoder 及指定合法 base 范围成立。扩展到更多或动态 decoder 时必须重新检查像集。此构造证明更强条件也有实例，不把它误报为新增独立记忆或智能。

## 4. 构造 B：CRT 的多域独立记忆对照

### 4.1 list 的元素取自商环

取互异素数 \(p_1,\ldots,p_s\)，\(M=\prod_i p_i\)，
\(R=\mathbb Z/M\mathbb Z\)，\(B\in R^N\)。当 \(s>1\)，R 不是域：存在非零零因子。真正的 field 是各 \(F_{p_i}\)。（R1）

decoder 取：
\[
\pi_i:R\to F_{p_i},\qquad\pi_i(b)=b\bmod p_i.
\]
这是合法商映射。CRT 给出
\[
\Phi:R\overset{\cong}{\longrightarrow}\prod_iF_{p_i}.
\]

**P3：完整余数组与一个 cell 双射。** 若两个规范代表有相同全部余数，其差被每个素数整除，故被 M 整除；范围限制给出两者相等。任意余数组的存在性由下面的构造直接提供。

### 4.2 独立写入推导

令
\[
Q_i=M/p_i,\quad e_i=Q_i(Q_i^{-1}\bmod p_i)\bmod M.
\]
于是 \(\pi_i(e_i)=1,\ \pi_k(e_i)=0\ (k\ne i)\)，并有
\[
b=\sum_i m_i e_i\pmod M.
\]

**P4：只改一个域余数。** 将 \(\pi_i(b)\) 写成 v：
\[
\delta=(v-\pi_i(b))\bmod p_i,\qquad
b'=b+\delta e_i\pmod M.
\]
投影到目标域得到 v，投影到其他域增量为 0。应用到 list 的位置 j，其他 list 元素也不变。这是由 CRT 得到的独立更新，不是对所有 decoder 都必须成立的课题要求。（R1–R2）

### 4.3 最小手算

\(p_1=2,p_2=3,M=6\)，\(e_2=3,e_3=4\)。想存 \((1\in F_2,2\in F_3)\)：
\[
b=1\cdot3+2\cdot4=11\equiv5\pmod6.
\]
于是 \(\pi_2(5)=1,\ \pi_3(5)=2\)，确为不同域上的不同结果。

只把 \(F_2\) 中记忆从 1 改成 0：
\[
\delta=1,\qquad b'=5+1\cdot3=8\equiv2\pmod6.
\]
现在 \(\pi_2(2)=0,\ \pi_3(2)=2\)。在 \(B=(5,2)\) 上只更新第一个元素，变成 \((2,2)\)；读一 cell、写一 cell，共两 cell，激活和修改比例均为 1/2。扩展 N 后为 1/N。

**必须保留的反例**：\(\pi_2(1)=\pi_2(3)=1\)。所以 \((b,\pi_2)\mapsto\pi_2(b)\) 不单射，加上 decoder 名字也不能修复这个碰撞。构造 B 不能被用来宣称满足用户的强 one-to-one。

### 4.4 容量与运算范围

一个 cell 有 \(M=\prod p_i\) 个可能状态，其信息容量是 \(\log_2M=\sum_i\log_2p_i\)。模 6 的 cell 需要 3 个固定长度 bits，独立定长存 mod 2 与 mod 3 也共需 \(1+2=3\) bits。这里没有无损压缩收益。（直接计数）

CRT 还保证 \(\pi_i(b+c)=\pi_i(b)+\pi_i(c)\)、\(\pi_i(bc)=\pi_i(b)\pi_i(c)\)。这是跨域并行代数计算的候选基础；这种计算本身还不是智能推理。独立域也不等于有“关系重叠”；要表达关联必须额外定义约束或耦合算子。

## 5. 局部读取与严格单射的边界

**P5（本项目限制证明）**：对自由 list \(A^N\)，一次没有读取全体坐标、也没有附带汇总状态的确定性查询，不能唯一识别整个 B。

证明：选择一个本次未读坐标，只改变它。所有被读内容相同，执行轨迹和结果不变，却得到两个不同 B。故非单射。即使寻址自适应，该构造依然保持每一步已读取内容不变。

所以 A 的“完整输出对完整 base 单射”和“一次部分读取”属于不同接口。局部读出可以唯一恢复局部 \(b_j\)，不能说恢复整个 B。R5 的局部解码也是对查询部分的恢复；若未来引入冗余码/缓存，必须把它们计入状态并重检前提。

另一个直接结论：D 对 B 单射时，\(B'\ne B\Rightarrow D(B')\ne D(B)\)。因此“每个完整 decoder 单射”与“修改后其他完整 decoder 不变”不能同时成立。用户并未要求后者，本项目不附加它。

## 6. 动态 decoder 与后续研究假说

**项目扩展定义**：
\[
D_t=(F_t,\alpha_t,\beta_t,\ldots),\quad
(B_{t+1},D_{t+1})=U_{S_t}(B_t,D_t,x_t).
\]
在固定域中改变非零 \(\alpha_t\) 或 \(\beta_t\)，即可保持可逆性同时改变解码结果。若 D 随时间改变，one-to-one 输入必须包含 D 的完整参数；仅写 field 名称不够。若改变域本身，还要给出新表示及迁移规则。（R1；运行时记忆动机参照 R8）

可研究的递进任务：

1. **局部修复**：增加域上的校验关系，从部分状态恢复擦除值。读、写与修复开销分别测量；R4–R7 表明这些目标需要考虑码率和错误模型。
2. **自组织记忆**：学习或演化局部更新算子，验证是否自行形成稳定模式；R9 是邻接证据，尚未迁移到本构造。
3. **智能行为**：预先定义未见规则组合/迁移任务及对照，考察能力是否来自记忆动力学；R8、R10 不能代替此实验。

这些是待验证假说。当前可证明的 base case 是基础读写、保持、指定唯一性与 CRT 独立更新。
