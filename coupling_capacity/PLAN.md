# PLAN_COUPLING.md — 预注册：s-槽耦合容量实验

2026-09-08；前置研究 RESEARCH.md。

## 实验设计

- 照片：12 张（data/photos/），128×128，6-bit 量化
- s 值：{1, 2, 3, 4}（使用前 s×floor(12/s) 张照片）
- 实验 A：100% 字段污染 → 观察哪些照片降级
- 实验 B：变化字段污染率 ε ∈ {0.01, 0.02, 0.05, 0.10, 0.20, 0.50, 1.0} → 测 PSNR
- 实验 C：错误位置 IoU 测量 → 量化同字段 vs 跨字段的耦合程度

## Hypothesis

| 编号 | 假设 | 指标 | 阈值 | 失败条件 |
|---|---|---|---|---|
| H_A1 | 字段 0 100% 污染时，正好 s 张照片 PSNR 下降 | 降级照片数 | = s | ≠ s |
| H_A2 | 同字段照片错误位置 IoU 接近 1 | IoU | > 0.95 | ≤ 0.95 |
| H_A3 | 跨字段照片错误位置 IoU 接近 0 | IoU | < 0.05 | ≥ 0.05 |
| H_A4 | per-photo PSNR 与 s 无关（同等 ε 下各 s 曲线重合） | PSNR 差值 | 最大差 < 1 dB | ≥ 1 dB |
| H_A5 | 零交叉字段污染：未被污染字段的照片 PSNR 不变 | PSNR 残差 | = 0.0 dB | > 0.0 dB |

阈值来源：H_A1/H_A5 为精确数学结论；H_A2 来自理论 IoU=1.0；H_A3 来自独立随机的 IoU≈ε²≈0；H_A4 来自 RESEARCH §2.3 的等价性推导。
